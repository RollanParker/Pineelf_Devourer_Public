# Pineelf_Devourer

A modern third-person MMORPG inspired by the exploration, progression, and social gameplay of classic EverQuest, built with Unity 6 and C#.

---

## Project Status

Pineelf_Devourer is currently in active early development.

The project is focused on building a clean, scalable architecture before implementing gameplay systems.

Current development includes:

- Player architecture
- Unity Input System
- Scene management
- Project framework
- Documentation
- GitHub workflow

---

## Technologies
